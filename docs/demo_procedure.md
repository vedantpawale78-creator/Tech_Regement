# Demo Procedure

1. Explain the project objective and architecture.
2. Run `demo_simulator.py` to generate synthetic alert data.
3. Start the Streamlit dashboard (`streamlit run dashboard.py`).
4. Show the dashboard, explaining total alerts, verified vs suppressed, and bandwidth reduction.
5. Run `detect.py` using a sample video or webcam to show live YOLO detection and zone rendering.
6. Explain the semantic alert format (JSON).
7. Run `benchmark.py` and display the generated CSV/JSON results.
